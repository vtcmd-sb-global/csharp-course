# C# Programming Course

Welcome to the **C# Programming Course**.

This course takes you from C# fundamentals to advanced C# and professional application development.

## Course Levels

### Beginner

- C# Fundamentals
- Variables
- Data Types
- Operators
- Conditions
- Loops
- Methods
- Arrays
- Collections

### Intermediate

- Classes
- Objects
- Constructors
- Properties
- Encapsulation
- Inheritance
- Polymorphism
- Interfaces

### Advanced

- Generics
- Delegates
- Lambda Expressions
- LINQ
- Exception Handling
- JSON
- Async/Await
- SQL Server
- ASP.NET Core Web API
- Dependency Injection
- SOLID Principles

## Course Structure

The course contains **18 sessions**, with each session lasting approximately **2 hours**.

## Student Expectations

Students are expected to:

1. Read the lesson material.
2. Type and execute the examples themselves.
3. Complete the exercises.
4. Complete the assignments.
5. Practice outside the classroom.
6. Build the final project.
